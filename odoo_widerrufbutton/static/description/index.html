Widerrufbutton Website

Withdrawal request form for Odoo Website, Portal and backend teams

Add a clear withdrawal entry point to your Odoo website and manage incoming withdrawal requests directly in Odoo.

Website form and confirmation flow

  • Public withdrawal pages at /widerruf and /vertrag-widerrufen.
  • Required customer contact and order or invoice reference fields.
  • Review step before final submission.
  • Optional attachment upload with configurable file types and size limit.

Backend management

  • Each submission is stored as a withdrawal record in Odoo.
  • Automatic request numbering and customer acknowledgement e-mail.
  • Configurable internal notification and follow-up activity.
  • Portal visibility can be enabled for logged-in customers.

Optional extensions

  • odoo_widerrufbutton_sale links requests with sales orders.
  • odoo_widerrufbutton_account links requests with invoices.
  • E-mail mismatch warnings help operators review linked documents.
